# AtlassianPSVII.ServerType

## SYNOPSIS

Enumeration of server types supported by AtlassianPSVII.

## DESCRIPTION

This enumeration lists the server types supported by AtlassianPSVII and it's modules.

_This enumeration will continue to grow with new additions to the modules._

## Accepted values

### BITBUCKET

AtlassianPSVII's representation of all [Bitbucket](https://www.atlassian.com/software/bitbucket) products.

This type of server is used by:

* [BitbucketPS](/module/BitbucketPS)

### CONFLUENCE

AtlassianPSVII's representation of all [Confluence](https://www.atlassian.com/software/confluence) products.

This type of server is used by:

* [ConfluencePSVII](/module/ConfluencePSVII)

### JIRA

AtlassianPSVII's representation of all [Jira](https://www.atlassian.com/software/jira) products.

This type of server is used by:

* [JiraPSVII](/module/JiraPSVII)
